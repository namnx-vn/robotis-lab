# ADR-0001: Simulation-first robot with deterministic motion safety

Status: Accepted for Sprint 01, 2026-10-19.

Decision: Webots `.wbt` + `.proto` + Python controller. Define all 10 joint IDs
in `configs/robot.json`; generate the static PROTO so motor names and limits match.
Separate deterministic Python motion/safety module from Webots API adapter.

Reason: repeatable dynamics and explicit safety allow a smaller prototype to be tuned
before servo purchases. No LLM/API is in the servo control loop.

Trade-offs: simplified rigid-box model, assumed mass/friction/torque, no inertial balance;
scripted neutral hold may fall. Generation adds a source-of-truth step before modifying
PROTO by hand. A separate Arduino adapter comes only after hardware acceptance gates.

Validation: `python tools/verify_project.py`; `python -m unittest discover -s tests -v`;
then real Webots smoke run and quantitative standing trials later.
